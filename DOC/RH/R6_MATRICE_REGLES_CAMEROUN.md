# R6 — MATRICE DES RÈGLES CAMEROUNAISES— 2026-09-29

Source principale : **Code du travail camerounais, Loi n° 92/007 du 14 août 1992**
(version consolidée, extraits ILO/natlex et textes officiels).
Règles sociales complémentaires : régime des risques professionnels (AT/MP),
prestations sociales (CNPS). La politique GPJ est **distincte** de la loi :
jamais présentée comme obligation légale.

Colonnes : Situation | Base juridique | Article | Effet contrat | Effet paie |
Durée | Justificatif | Validation | Risque | Source.

Légende Source : **LOI** = Code du travail 92/007 ; **CONV** = convention
collective / accord d'établissement ; **POL** = politique GPJ (choix interne) ;
**CFG** = configuration entreprise (paramétrable, par défaut proposé).

---

## 1. Maladie (constatée)

| Situation | Maladie |
|---|---|
| Base juridique | Code du travail, suspension du contrat pour maladie dûment constatée |
| Article | Art. 32 (c) [et 63/65 général] |
| Effet contrat | Contrat **suspendu** (pas de rupture) |
| Effet paie | Suspension de la fourniture du travail + privation de rémunération pour la période couverte par la CNPS ; **rémunération du maintien = décision GPJ/contrat** (maintenir la gratification n'est PAS une obligation légale) |
| Durée | **6 mois max** (art. 32-c, prorogeable jusqu'au remplacement effectif) |
| Justificatif | Certificat médical délivré par un médecin agréé / établissement hospitalier reconnu |
| Validation | RH (approbation), pièce jointe obligatoire |
| Risque | Absence de certificat → l'absence devient injustifiée ; maintien du salaire sans base légale → risque de requalification |
| Source | LOI (art. 32-c) + **POL/CFG** pour le taux de maintien |

## 2. Congé de maternité

| Situation | Maternité |
|---|---|
| Base juridique | Code du travail |
| Article | Art. 84 (2)-(3), suspension art. 32 (d) |
| Effet contrat | Contrat **suspendu** ; interdiction d'emploi pendant la période ; aucune rupture de ce chef |
| Effet paie | Prestations en espèces (indemnité journalière) ; **complément éventuel = politique GPJ** |
| Durée | **14 semaines** (dont 4 avant la date présumée), +6 semaines en cas de maladie certifiée liée à la grossesse/couches ; début anticipé → allongement pour garantir les 14 semaines (art. 84-3) |
| Justificatif | Certificat de grossesse médical + certificat d'accouchement |
| Validation | RH (approbation), dossier CPNS/CNPS requis |
| Risque | Licenciement pendant la période → nullité + indemnités |
| Source | LOI (art. 84, 32-d) |

## 3. Accident du travail / maladie professionnelle

| Situation | Accident du travail / maladie professionnelle |
|---|---|
| Base juridique | Code du travail (suspension) + régime AT/MP (loi n° 77-11 du 13/07/1977 ; risques professionnels CNPS) |
| Article | Art. 32 (g) ; régime AT/MP |
| Effet contrat | Contrat **suspendu** pendant l'indisponibilité |
| Effet paie | **INDEMNISATION_EXTERNE** (indemnités journalières AT/MP) ; l'employeur ne paie pas le salaire (sauf complément GPJ) |
| Durée | Durée de l'indisponibilité médicalement constatée (pas de plafond art. 32-g) |
| Justificatif | Certificat médical AT/MP, procès-verbal / déclaration employeur, avis du médecin |
| Validation | RH (approbation) + déclaration dans les délais |
| Risque | Défaut de déclaration → prise en charge sur l'employeur, indemnités, sanctions |
| Source | LOI (art. 32-g + régime AT/MP) |

## 4. Mise à pied disciplinaire

| Situation | Mise à pied disciplinaire |
|---|---|
| Base juridique | Code du travail — discipline |
| Article | **Art. 30 (1)-(3)** — seule sanction pouvant entraîner privation de salaire ; interdiction des amendes |
| Effet contrat | Contrat **suspendu** pendant la MAP (art. 32-e) |
| Effet paie | **RETENUE** (privation de salaire) strictement proportionnée aux jours non prestés ; **aucun prélèvement forfaitaire type amende** (art. 30-1) — interdit |
| Durée | **8 jours ouvrables max**, fixée au moment où elle est prononcée (art. 30-3-a) |
| Justificatif | Notification écrite **avec motifs** (art. 30-3-b) ; communication à l'inspection du travail **dans les 48 h** (art. 30-3-c) |
| Validation | Approbation (RH/DRH), preuve de notification + preuve communication inspection |
| Risque | Non-respect d'un des 3 points → **mise à pied nulle de nul effet** ; motifs insuffisants en justice → **indemnité compensatoire** égale à la perte de salaire + dommages-intérêts (art. 30) |
| Source | LOI (art. 30, 32-e) |

## 5. Mise à pied conservatoire (enquête/discipline en cours)

| Situation | Mise à pied conservatoire |
|---|---|
| Base juridique | Jurisprudence / usage — pas de base légale explicite dans le Code (→ POlitique GPJ) |
| Article | — (usage ; à documenter comme **POL**) |
| Effet contrat | **SUSPENDU** (maintien du contrat le temps de l'enquête) |
| Effet paie | À déterminer (en général NON_REMUNERE le temps de l'enquête, réversibilité si non-lieu selon la politique GPJ) |
| Durée | Courte, bornée par la décision disciplinaire finale — configurable, jamais ouverte |
| Justificatif | Rappel à l'enquête, notification |
| Validation | Approbation RH |
| Risque | Durée excessive ou retenue injustifiée → requalification en sanction illégale |
| Source | **POL** + CFG |

## 6. Suspension pour autre cause légale (service militaire, fonctions publiques, garde à vue…)

| Situation | Autres suspensions légales |
|---|---|
| Base juridique | Code du travail |
| Article | Art. 32 (a) employeur sous les drapeaux ; (f) congé d'éducation ouvrière — art. 91 ; (h) fonctions politiques/administratives d'accord parties ; (i) garde à vue/détention préventive ; (j) suivi du conjoint muté ; plafonds divers |
| Effet contrat | Contrat **suspendu** |
| Effet paie | NON_REMUNERE (ou INDEMNISATION_EXTERNE si prestation) — selon cause, **CFG** |
| Durée | Spécifique à chaque cause (bornée par l'événement) |
| Justificatif | Pièces officielles (ordre d'appel, jugement, notification) |
| Validation | Approbation (RH) |
| Risque | Traiter comme une sortie ou une absence injustifiée → fausse rupture |
| Source | LOI (art. 32) + **CFG** pour l'effet paie |

## 7. Chômage technique

| Situation | Chômage technique |
|---|---|
| Base juridique | Code du travail |
| Article | Art. 32 (2) — « le contrat de travail est suspendu pendant la durée du chômage technique dans la limite de **6 mois maximum** » |
| Effet contrat | Contrat **suspendu** |
| Effet paie | À défaut de convention collective, conditions d'indemnisation fixées par **arrêté du ministre chargé du Travail** (art. 32 al. 3) → **A_DETERMINER / MANUEL** selon configuration |
| Durée | ≤ 6 mois |
| Justificatif | Décision de fermeture/réduction, information Inspection du travail |
| Validation | Approbation (RH/DRH) — cas collectif |
| Risque | Dépassement 6 mois → requalification ; absence d'indemnisation quand elle est due |
| Source | LOI (art. 32-2/3) + **CFG** |

## 8. Congé annuel payé

| Situation | Congé annuel |
|---|---|
| Base juridique | Code du travail |
| Article | Art. 89 (1) — **1,5 jour ouvrable par mois de service effectif**, soit 18 jours ouvrables/an (sauf clauses plus favorables) |
| Effet contrat | Contrat **ACTIF** (simple situation datée, pas de suspension) |
| Effet paie | **MAINTIEN_REMUNERATION** (congé payé) + allocation de congé selon les modalités |
| Durée | 1,5 j/mois × mois effectifs ; report régi par usage/convention |
| Justificatif | Demande approuvée ; planification |
| Validation | Approbation du congé (workflow existant) |
| Risque | Prise avant acquisition / sans solde → écart de solde |
| Source | LOI (art. 89) + **CFG** (règles de report) |

## 9. Congé sans solde / permission exceptionnelle / congé d'éducation

| Situation | Congé sans solde / permission / éducation ouvrière |
|---|---|
| Base juridique | Code du travail — congé d'éducation ouvrière art. 91 |
| Article | Art. 91 (éducation ouvrière) ; sans solde/permission = **POL** |
| Effet contrat | Contrat **ACTIF** (situation datée) |
| Effet paie | SANS_SOLDE → NON_REMUNERE ; permission exceptionnelle → **CFG** (souvent MAINTIEN ou NON_REMUNERE) ; éducation ouvrière → maintien selon art. 91 & prestations |
| Durée | Bornée par les dates |
| Justificatif | Demande approuvée / pièce CNPS pour l'éducation ouvrière |
| Validation | Approbation |
| Risque | Assimiler à une rupture |
| Source | LOI (art. 91) + **POL/CFG** |

## 10. Absence autorisée vs absence injustifiée

| Situation | Absence (autorisée / injustifiée) |
|---|---|
| Base juridique | Discipline & règlement intérieur — l'absence injustifiée relève du pouvoir disciplinaire (sanction, art. 30) |
| Article | Absence injustifiée **R3 / règlement** ; sanctions art. 30 |
| Effet contrat | Contrat **ACTIF** (constat, pas une suspension) |
| Effet paie | Absence injustifiée → **RETENUE** sur les jours d'absence (retenue = absence de travail, **pas une amende**) ; absence autorisée → **CFG** |
| Durée | Bornée par les dates |
| Justificatif | Pointages R3 + justificatif éventuel (autorisation) |
| Validation | Constat RH (déclaration) ; autorisée nécessite approbation GPJ |
| Risque | Assimiler absence injustifiée à une mise à pied illégale ; retenue punitive > jours absents → **amende déguisée (interdite)** |
| Source | **POL** (constat) + LOI (interdiction amendes, art. 30) |

## 11. Sortie définitive

| Situation | Sortie (licenciement / démission / fin de contrat) |
|---|---|
| Base juridique | Code du travail — rupture |
| Article | Art. 28-32 (rupture), préavis art. 32 (stipulé au contrat/convention, non imputable sur congés), motifs de licenciement |
| Effet contrat | Contrat **TERMINÉ** |
| Effet paie | Paiement au prorata jusqu'à la date de sortie + **indemnités éventuelles (préavis, congés non pris, indemnité de licenciement)** — calculées selon rupture et mode de paie (R4) |
| Durée | Date de sortie (milieu de mois inclus) |
| Justificatif | Notification écrite, lettre, PV, solde de tout compte |
| Validation | Approbation RH, permission dédiée |
| Risque | Rupture sans notification/motif → dommages-intérêts ; date rétroactive mal renseignée → mauvaise paie |
| Source | LOI (rupture, préavis) + **POL** |

## 12. Réembauche

| Situation | Réembauche (nouvel épisode d'emploi) |
|---|---|
| Base juridique | Nouveau contrat de travail |
| Article | — (nouvel engagement) |
| Effet contrat | **ACTIVE** (nouvel épisode) ; l'ancien épisode sorti reste conservé |
| Effet paie | Reprise de la paie à la date de réembauche ; nouveau salaire éventuel |
| Durée | À partir de la date de réembauche |
| Justificatif | Nouveau contrat / dossier d'embauche |
| Validation | Approbation RH, permission dédiée |
| Risque | Effacer la trace de sortie (interdit) ; mélanger ancien/nouveau épisode |
| Source | **POL** (procédure) |

## Note méthodologique

- **LOI** : règle impérative (plafonds art. 30/32, art. 84, 89, 91) — le logiciel la
  traduit en **garde-fous durs** (ex. mise à pied ≤ 8 jours ouvrables, interdiction
  de « detailsFinanciers » punitif).

- **POL / CFG** : décisions GPJ paramétrables (taux de maintien, retenue des jours
  d'absence, complément de maternité…). **Aucune politique GPJ n'est libellée comme
  obligation légale dans l'UI** (libellés type « règle GPJ configurable »).

- Toute règle dont la base légale n'a pu être vérifiée (ex. mise à pied
  conservatoire, durée de report des congés) est marquée **POL/CFG** et documentée,
  jamais présentée comme un article.

- La matrice de vérité (mapping opérationnel des impacts) est dans
  `PHASE_R6_CONCEPTION_V2_CYCLE_VIE_2026-09-29.md` §23.
