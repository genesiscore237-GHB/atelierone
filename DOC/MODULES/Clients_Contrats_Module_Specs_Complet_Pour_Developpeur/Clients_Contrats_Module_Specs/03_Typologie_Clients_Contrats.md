# 03 — TYPOLOGIE CLIENTS & CONTRATS

### 1. Types de Clients (obligatoire)

| Code | Libellé | Description | Comportement système |
|------|---------|-------------|----------------------|
| particulier | Particulier | Client individu | Paiement souvent comptant ou immédiat |
| entreprise_contrat | Entreprise sous contrat | Flotte avec engagement | Facturation selon contrat, crédit possible, véhicules liés |
| entreprise_ponctuelle | Entreprise ponctuelle | Sans contrat formalisé | Traitement proche du particulier, mais raison sociale |

**Règle :** Le type influence les champs affichés, les conditions de paiement proposées et les écrans de suivi.

### 2. Types de Contrats recommandés

- Maintenance préventive (échéancier)
- Forfait mensuel / trimestriel
- À l’intervention (open)
- Mixte (forfait + hors forfait)
- Autres (paramétrable)

### 3. Conditions de paiement standard

- Comptant
- 7 jours
- 15 jours
- 30 jours
- 45 jours
- Fin de mois
- Sur relance / selon accord
- Autre (texte libre)

### 4. Statuts Client

- Actif
- Bloqué (crédit dépassé ou litige)
- Inactif
- Contentieux

### 5. Statuts Contrat

- Brouillon
- Actif
- Suspendu
- Expiré
- Résilié

### 6. Segmentation utile pour le pilotage

- Clients à fort volume
- Clients avec retards récurrents
- Contrats arrivant à échéance dans les 30/60 jours
- Clients sans activité depuis X mois
