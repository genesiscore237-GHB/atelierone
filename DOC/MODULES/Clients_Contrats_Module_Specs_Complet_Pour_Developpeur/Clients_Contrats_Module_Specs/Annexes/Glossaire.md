# Glossaire Clients & Contrats

- **Client sous contrat** : Entreprise ayant un engagement formalisé de maintenance
- **Entreprise ponctuelle** : Entreprise sans contrat cadre
- **Solde client** : Montant total encore dû (factures ouvertes – paiements)
- **Encours** : Total des factures non soldées
- **Relance (Dunning)** : Action de rappel de paiement
- **Facturation groupée** : Facture récapitulative de plusieurs interventions sur une période
- **Flotte** : Ensemble des véhicules d’un client entreprise
- **Avenant** : Modification d’un contrat existant
- **Contentieux** : Situation de litige ou d’impayé grave
