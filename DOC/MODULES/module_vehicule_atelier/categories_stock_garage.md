## Notes d'utilisation pour l'IA / le système

1. **Recherche** : permettre la recherche par :
   - Nom de la catégorie / sous-catégorie
   - Mot-clé dans le nom de l'article
   - Référence constructeur ou équipementier
   - Compatible véhicule (marque, modèle, année, motorisation)

2. **Enregistrement d'un nouvel article** :
   - Obligatoire : Catégorie principale + Sous-catégorie
   - Recommandé : Marque, Référence, Prix d'achat, Prix de vente, Stock mini, Emplacement
   - Optionnel : Photo, N° de série/lot, Fournisseur principal, Lien TecDoc

3. **Classification ABC recommandée** (à ajouter en attribut) :
   - **A** : Haute rotation / haute valeur (filtres, plaquettes, huiles, batteries…)
   - **B** : Rotation moyenne
   - **C** : Faible rotation / stock de sécurité

4. **Types de stock à distinguer** :
   - Pièce neuve OEM
   - Pièce neuve adaptable (aftermarket)
   - Échange standard
   - Pièce de réemploi (PIEC)
   - Consommable
   - Outillage (immobilisation)
