# Onglet 6 — Contrôle Qualité

## Objectif
Garantir que le véhicule ne part pas sans validation formelle.

## 6.1 Checklist qualité (configurable)
Exemples de points :
- Travaux conformes au devis autorisé
- Serrages / couples
- Niveaux de liquides
- Absence de fuite
- Codes défaut effacés / recontrôle
- Propreté
- Protections / outils retirés
- Essai des systèmes réparés

Chaque point : OK / Non OK / Non applicable + commentaire.

## 6.2 Essai routier
- Réalisé : Oui / Non
- Distance / durée
- Conducteur
- Observations
- Résultat : Satisfaisant / Réserves / Échec

## 6.3 Décision
| Action | Effet |
|--------|-------|
| Valider le QC | → PRET_A_LIVRER |
| Rejeter | Retour EN_COURS + motif obligatoire + responsable |

## 6.4 Traçabilité
- Qui a contrôlé
- Quand
- Résultat
- Photos éventuelles

## 6.5 Règle
Aucun passage à « Prêt à livrer » sans QC validé (sauf dérogation chef explicitement tracée).
