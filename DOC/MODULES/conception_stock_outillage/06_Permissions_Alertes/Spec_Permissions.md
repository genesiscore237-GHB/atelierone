# Permissions & Alertes

## Matrice permissions

| Action | Magasinier | Technicien | Chef atelier | Boss |
|--------|------------|------------|--------------|------|
| Catalogue : créer / modifier article | ✓ | — | lecture | ✓ |
| Voir stock tous emplacements | ✓ | limité | ✓ | ✓ |
| Approvisionner bureau | ✓ | — | ✓ | — |
| Prêter outil | ✓ | demander | ✓ | — |
| Retourner outil | ✓ | — | ✓ | — |
| Dotation conso | ✓ | — | ✓ | — |
| Servir pièce pour OR | ✓ | — | ✓ | — |
| Voir prêts en retard | ✓ | ses prêts | ✓ | ✓ |
| Inventaire / ajustement | ✓ | — | ✓ | ✓ |
| Voir valorisation stock | — | — | ✓ | ✓ |

## Alertes prioritaires

1. **Prêts en retard** (tableau + notification)
2. **Stock bureau sous seuil** (suggestion d’approvisionnement)
3. **Stock magasin sous seuil** (réappro fournisseur)
4. **Outil en réparation depuis > X jours**
5. **Écart d’inventaire significatif**
