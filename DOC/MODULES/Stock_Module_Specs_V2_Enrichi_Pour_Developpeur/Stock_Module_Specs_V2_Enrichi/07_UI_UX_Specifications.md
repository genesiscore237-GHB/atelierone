# 07 — SPÉCIFICATIONS UI / UX

### Principes
- Recherche article ultra-rapide (code, désignation, réf OEM, équivalences)
- Couleurs : Rouge = rupture ou DLC dépassée | Orange = stock bas ou DLC proche | Vert = OK
- Actions fréquentes ≤ 3 clics
- Mobile-friendly souhaitable pour le magasinier

### Écrans prioritaires
1. Liste Articles (filtres : catégorie, statut, rupture, bas, DLC, origine, core)
2. Fiche Article (onglets : Infos, Stock par emplacement, Équivalences, Historique, Fournisseurs)
3. Nouvel Mouvement (wizard contextuel selon type — reconditionnement en double zone)
4. Session d’Inventaire
5. Tableau de bord (valeur stock, ruptures, bas, DLC, mouvements du jour, réservations)
6. Contenu d’un emplacement
7. Historique complet d’un article

### Messages clés
- « Stock disponible insuffisant (réservations en cours) »
- « Ce reconditionnement va générer deux mouvements liés. Confirmer ? »
- « Motif obligatoire pour une perte/vol/casse »
- « Article périmé — sortie bloquée ou à confirmer »
