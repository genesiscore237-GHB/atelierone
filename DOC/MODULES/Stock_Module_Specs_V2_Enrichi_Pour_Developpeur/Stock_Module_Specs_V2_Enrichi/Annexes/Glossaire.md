# Glossaire Stock Automobile

- **PMP** : Prix Moyen Pondéré
- **OR** : Ordre de Réparation
- **Reconditionnement** : Transformation d’une grande unité (fût) en unités plus petites
- **Supersession** : Remplacement d’une référence par une nouvelle
- **Core / Échange standard** : Pièce vendue avec consigne (coquille à retourner)
- **Stock réservé** : Quantité mise de côté pour un OR ou un client
- **DLC** : Date Limite de Consommation / péremption
- **Origine/Qualité** : Constructeur / OEM équivalent / Aftermarket
- **Rupture** : Stock ≤ 0
- **Stock disponible** : Stock actuel – Stock réservé
